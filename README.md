# GitHub Contribution Art

Browser tools for designing patterns on a GitHub-style contribution graph.

## Contents

- `app/` — modular editor with patterns, undo/redo, localization and image export.
- `legacy/` — earlier standalone implementation kept for reference.

## Usage

Open `app/index.html` in a modern browser. No build step is required.

## Status

Functional front-end experiment.
